### W3 P0-3 记忆层（中；主线对齐 TencentDB-Agent-Memory，符合已选定的 Context Lifecycle 设计）

> 2026-09-28 用户裁定：git 化记忆 + 后台整理 worker + git 冲突修复方向**不采纳**（与 AIOS 已有的预算降级/ref 外置架构偏离过大）。记忆层主线回到 TD 那套：

- **注入方式一等公民**：召回注入按 InjectionMode 四档（direct / summary / tool / reference）显式声明，配 Agent Loadout 绑定校验——接到 memo recall 与 ContextDB 注入路径。
- **预算降级阶梯**：full → summary+ref → ref-only；不得因超预算静默丢失，压缩必须验证 must-preserve 与 evidence 可达性（`scripts/lib/contextdb/search/budget.mjs` 已有基础，补契约与验证）。
- **ACL 纯函数 + 绑定校验**：memo supersede / publish gate 用 checkPermission / canBindAsset 式纯函数（private 对 admin 也 DENY），runtime 可测。
- **result_ref offload**：工具结果与记忆外置为引用，保留可恢复原文与来源链（runtime provenance）。
- 检索排序增强（与存储表示正交，保留）：BM25 + 实体加成 + sigmoid 归一融合排序（零 embedding 先行）。
- memory forget 溯源删除：检视贡献来源 → 排除准入 → 删派生留源，接到 result_ref 来源链。
- provenance 晋升门槛：candidate promotion 沿用 dream lane 默认 DENY + 提案制，门槛设计参考 OpenClaw。

**落地**：`scripts/lib/memo/`、`scripts/lib/contextdb/`、`mcp-server/src/contextdb/`。
**验收**：注入档位显式可查；降级路径有 must-preserve 对照测试；ACL 纯函数单测覆盖 DENY 用例；forget 链路保留来源引用。
