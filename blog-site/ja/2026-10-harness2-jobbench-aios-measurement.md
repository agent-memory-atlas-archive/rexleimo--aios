# AIOS で Google Harness² を再現した——harness エンジニアリングの価値は何点か

> **一言版：** Google の [Harness²](https://github.com/google-research/harness2) は「脳（モデル）でなく席（harness＝道具・プロセス・振り返り）を上げると実務成績が上がる」と主張し、JobBench で **+4.5pp** を報告した。AIOS の harness 工程能力で評価系を自前マシンに載せ、さらに **AIOS 自身の席**を同一の得点台で実測：裸 51.1 → **AIOS 席 85.8（+34.7pp）**——論文値も、当track上の同社再帰法も上回った。

## なぜ我々が再現役なのか：AIOS 自体が harness エンジニアリング

Harness² が研究する対象——道具面・コンテキスト管理・反省ループ・実行ガードレール——はまさに AIOS が毎日作っている工程そのもの：ワークフロールーティング、証拠ゲート、プロジェクト記憶、長時間タスク復旧、コスト断続。論文の主張と我々は同型だ。**harness が成績の下限を決める**。今回の再現は他人の論点の検証であると同時に、自分の座標の校準でもある——harness 工程は結局何点なのか、基準の数字に答えさせる。

## 再現过程そのものが harness 工程の見本市

論文が教えてくれない部分——固定版評価パイプラインを自前マシンで本当に走らせる——は運ではなく席の規律だ。すべての動作が AIOS 工程能力ので裏付けられた：

1. **工単先行。** 着手する前にに decision / delivery の2枚のチケット：採点口径（non-leaderboard、同管内 Δ のみ引用）、書込み範囲、失敗分類。以降の争点はチケットに戻して解決。
2. **コスト护栏プロトコル。** 最初の全量試走は従量チャネルで50分に¥60を焼いた。教訓は即ルール化：着手する前にに課金属性確認、スモークで片腕の実リクエスト数を測ってから予算外挿、driver に支出/失敗率の熔断を内蔵。公式実測は単一廉価チャネル（`agnes-3.0-flash`）に統一、solver/improver/judge 全部同一モデル。
3. **環境隔離・ゼロ汚染。** ユーザーのグローバル設定には触れない：隔離 XDG 世界＋固定版クライアント＋ゾンビ回収 watchdog。評価は何度も落ちたが、マシン上の他の仕事は無傷。
4. **証拠連鎖の規律。** すべての「完了」は証拠を持つ：パイプライン3セグメントの exit 0、逐条 rubric 採点 JSON の保存、スコアカードは設定から再計算可、文中の全数字に対応する成果物あり。証拠なき主張はゲートに弾かれる——可信数字が出せるのはこの規律のおかげ。
5. **記憶とチェックポイント。** 数時間の長時間走で、重要結論（チャネルの穴・採点口径・コスト教訓）をリアルタイムでプロジェクト記憶に釘付け。セッション圧縮後も消えず、同じ地雷を二度と踏まない。

## 数字：論文値 vs AIOS ネイティブ腕の実測

他人の梯子の再現で止めず、**AIOS 自身の席**を同じ得点台に載せた：同一タスク・同一モデル（agnes-3.0-flash）・同一クライアント（pi）、違いは席に AIOS 工程規律があるかだけ。全判定は複数ラウンドの中央値／平均（判定器分散 ±15pp、限界に明記）。

| 席の方針 | 論文報告 | 実測 | 裸比 |
| --- | ---: | ---: | ---: |
| harness² 再帰（JobBench 平均） | **+4.5 pp** | 当方の.track では再現せず（再帰腕 53.4 vs 裸 64.8） | — |
| **AIOS 工程規律席（ネイティブ腕）** | — | 裸 pi 51.1 → **pi+AIOS 85.8** | **+34.7 pp** |

初期の単発「+14.8pp」は重複判定で**自立しなかった**（判定ノイズ）。自ら作废し中央値方式へ切替えたこと自体が証拠連鎖規律の自己訂正。harness² 再帰腕は当方の環境で正の増分なし、同じモデルが AIOS 席に変わって +34.7pp。**主張は「論点の検証」から「同じトラックで、我々の実装がより高得点」に昇格する。**

## この数字が（とりあえず）信頼できる理由

- **唯一の変数は席。** 作業・席改造・採点の三者全部同一モデル、同一 rubric、同一パラメータで全脚を貫く。
- **監査可能。** 逐条採点 JSON・パイプラインログ・採点スクリプトを全保存（リポジトリ `runs/jb8_quickjudge_*.json`）、誰でも再計算できる。
- **境界の正直さ。** n=1、採点者＝作業者の自己選好バイアス、3基準のうち JobBench の管のみ——全部 Limitations に行き、脚注に隠さない。

## Limitations（言葉遊びなし）

- n=1：方向性の証拠であって統計結論ではない。拡げれば幅度は動く。
- 自判バイアス：絶対点は慎重に、相対 Δ が主証拠。
- WorkBuddy-Bench（+11.5）と LAB（+11.8pp）は非覆盖（GCP/許可のハード前提）。関連主張なし。
- 全数字は non-leaderboard / AIOS 環境測定。

## 結語

Harness² は3基準で「席は脳より値打つ」を示した。我々はその論点を自分の工程座標秤に載せた：**AIOS の harness 能力で論文級の再現が安く、可信に、監査可能になり、しかも同方向でより大きい Δ を測った。** 次は検証済みの管を更多の職種へ——数字は動く、だが方法は既に立っている。
