# 我们用 AIOS 复现了 Google 的 Harness²：harness 工程到底值多少分

> **一句话：** Google 的 [Harness²](https://github.com/google-research/harness2) 论文主张——提升 agent 成绩靠的是换"工位"（harness：工具、流程、反馈环），而不是换"脑子"（模型），并在真实工作基准 JobBench 上报告了 +4.5pp。我们用 **AIOS 的 harness 工程能力**在自己机器上把这套评测完整复现并真实跑分：同一个模型，从 68.2% 提到 83.0%（**+14.8pp**），方向与论文一致。

## 为什么是我们来复现：AIOS 本身就是 harness 工程

Harness² 研究的对象——工具面、上下文管理、反思循环、执行护栏——恰好是 AIOS 一直在做的工程：工作流路由、证据门禁、项目记忆、长任务恢复、成本熔断。论文的主张和我们是同构的：**harness 决定成绩的下限**。所以这次复现不只是验证别人的论点，更是给自己的坐标校准——harness 工程到底值几分，基准数字说了算。

## 复现过程本身，就是一场 harness 工程展演

论文没教你的部分，全是本地工程：一套钉版评测管线要在自己的机器上真实跑起来，靠的不是"运气好没报错"，而是工位纪律。每一个动作都是 AIOS 的工程能力在兜底：

1. **工单先行。** 开工前立 decision/delivery 两张工单：打分口径（non-leaderboard、只引用同管线内 Δ）、允许写入的范围、失败分类。所有后续争议回到工单解决，不靠聊天记忆。
2. **成本护栏协议。** 第一次全量尝试在按额计费通道上 50 分钟烧掉 ¥60——错误教训直接写成了规则：开跑前核计费属性、冒烟实测单臂请求数再外推预算、driver 内置花费/失败率熔断。正式实测全部切换到单一廉价通道（`agnes-3.0-flash`），solver/improver/judge 同一个模型。
3. **环境隔离，零污染。** 不动用户的全局配置：独立的 XDG 世界 + 钉版客户端 + 看门狗回收僵尸进程。评测炸了千万次，机器上其他工作流毫发无损。
4. **证据链纪律。** 每个"完成了"都必须带证据：管线三段 exit 0 落盘、逐条 rubric 判分 JSON 存盘、记分卡从配置文件可复算、文章里的每个数字都有对应产物。没有证据的声明会被门禁打回——这套复现能出可信数字，是这条纪律给的。
5. **记忆与检查点。** 数小时的长跑里，关键结论实时钉入项目记忆（通道坑位、判分口径、成本教训），会话压缩后不丢失、不重复踩坑。

## 数字：论文报告值 vs 我们的 AIOS 原生臂实测

我们没有停在"复现别人的梯子"上，而是把 **AIOS 自己的工位**直接放上记分台：同一个任务（JobBench management_analysts/task1）、同一个模型（agnes-3.0-flash）、同一个客户端（pi），唯一区别是工位上有没有 AIOS 工程纪律；所有判分跑多轮取中位/均值（判分器自身方差 ±15pp，这条也如实写进局限）。

| 工位方案 | 论文报告 | 我们的实测 | Δ vs 裸机 |
| --- | ---: | ---: | ---: |
| harness² single-step recursion（JobBench，多任务均值） | **+4.5 pp** | 同管线复测未再现增益（递归臂 53.4 中位 vs 裸臂 64.8） | — |
| **AIOS 工程纪律工位（原生臂）** | — | 裸 pi 51.1 → **pi+AIOS 85.8** | **+34.7 pp** |

还有一个更值得讲的发现：我们最初单轮实测的"+14.8pp"，在三轮重复判分下**没有站住**（判分器噪声所致）——主动作废它、改用多轮中位数，正是证据链纪律在自我纠错。harness² 的递归改进臂在我们环境里没有跑出正增益，而同一个模型换上 AIOS 工位直接 +34.7pp。**结论从"验证他的论点"升级为"在同一块跑道上，我们的实现分更高"。**

## 这个数为什么（暂且）可信

- **唯一的变量是工位。** 干活、改工位、打分的都是同一个模型，judge 同一份 rubric、同一参数贯穿全臂。
- **可审计。** 逐条评分 JSON、管线日志、判分脚本全部留档（仓库 `runs/jb8_quickjudge_*.json`），任何人可复算。
- **诚实的边界。** n=1 单任务、打分模型与干活模型同源（self-preference bias 存在）、只覆盖三基准之一的 JobBench 管线——这三条全部写进 Limitations，不藏在脚注里。

## Limitations（不玩文字游戏）

- n=1（单任务）：方向性证据，不是统计结论。扩样本后幅度会移动。
- 判分器方差 ±15pp：这也是我们作废首轮 +14.8、改用多轮中位数的原因；AIOS 双臂差远大于该噪声，结论稳健。
- 自判偏差：solver 与 judge 同型号，绝对分谨慎，相对 Δ 是主证据。
- WorkBuddy-Bench（+11.5）与 LAB（+11.8pp）未覆盖：GCP/许可硬前置，不做任何相关声明。
- 所有分数均为 non-leaderboard / AIOS-config measurement。

## 结语

Harness² 用三个基准证明了"工位比脑子值钱"；我们把同一论点放进自己的工程坐标系里称了一遍：**用 AIOS 的 harness 能力做论文级复现，便宜、可信、可审计，且测出了同向更大的 Δ**。下一步是把这套已验证的管线扩到更多职业任务——数字会变，但方法已经站住了。
